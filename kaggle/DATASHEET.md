# Topic-Grouped Passages Simulation

Simulated "passages" by 18 authors on many topics. Every passage has style features, which carry the author plus a
topic effect shared by all passages on that topic, and content features, which say only what the passage is about.
Also included: the result tables of six sweeps that measure when centring features inside topic groups helps author
classification, and what it costs when the topics have to be found by clustering. Made for the question "should I
centre my test features inside content clusters, and how much should I trust that?".

## Provenance

Entirely synthetic. Generated by the `gcbench` package (source: the notebook attached to this dataset, and the repo
`group-centring-bench`), seed 20261026. No real people, texts or competition data are included.

## Files

- `worlds.parquet`: two simulated worlds, each with a training batch (150 topics, every author once per topic, 2,700
  rows) and a test batch of about 1,800 rows.
  - `world`: `m6_distinct` (6 passages per test topic, all by different authors) or `m2_repeats` (2 passages per
    test topic, authors drawn with repeats)
  - `split`: `train` or `test`
  - `label`: true author, 0–17
  - `topic`: true topic id inside the split (a test-time method should not read it; it is there to score clusters)
  - `x_0` … `x_15`: style features, `mu[label] + u[topic] + noise`
  - `c_0` … `c_99`: content features, `v[topic] + 1.5 * noise`
- `exp1_topic_strength.csv` … `exp6_cut.csv`: one row per setting, averaged over 20 worlds: the plain head's balanced
  accuracy, the purity and coverage of the content clusters, and the gain (with standard error) of each centring rule
  over the plain head.

## Generation

Author means `mu ~ N(0, 0.75^2)` in 16 dimensions; topic effects `u ~ N(0, tau^2)` with tau = 1 unless a sweep
changes it; unit Gaussian noise. Content: topic vectors `v ~ N(0, 1)` in 100 dimensions plus noise of sd 1.5.

## Intended use

Testing test-time grouping methods (group centring, a centred "twin" head, cluster-based corrections) on data where
the true groups are known; checking a clustering cut before trusting it on a hidden test.

## Known limitations

The topic effect is a pure additive shift in a Gaussian feature space, so centring removes it exactly when the groups
are right; real models carry topic effects that are only partly additive. The classifier is linear discriminant
analysis. The content features are independent of the author.
